표준점수 — 개념과 원리

📌 표준점수란?

원점수를 전체 수험생의 평균과 표준편차를 이용해 상대적인 위치로 변환한 점수입니다.

계산 원리 (이해 참고용)

Z = (원점수 − 평균) ÷ 표준편차

→ 영역별 고유 변환식 적용 후 최종 제공

(교육부·수능출제기관이 직접 산출)

핵심 포인트

•시험이 어려울수록 → 만점 표준점수 상승

•시험이 쉬울수록 → 만점 표준점수 하락

•국어·수학은 보통 130~150점대 만점

•탐구 영역은 보통 60~75점대 만점

백분위 — 개념과 해석

📌 백분위(百分位)란?

나의 표준점수보다 낮은 표준점수를 받은 수험생의 비율을 나타냅니다. 0~100 사이의 정수로 표시되며, 숫자가 클수록 높은 성취를 의미합니다.

예시로 이해하기

백분위 93

나보다 낮은 점수를 받은 수험생 = 93%

상위 7%

→ 백분위 93 = 전체 수험생 중 상위 7% 수준

백분위 계산 방식

•(내 점수 미만 인원) ÷ 전체 응시자 × 100

•소수점 첫째 자리에서 반올림 → 정수 표시

•동점자가 많으면 같은 백분위일 수 있음

•만점자 백분위 = 100점이 아닐 수 있음

백분위 활용 시 주의점

•영역별 응시 인원이 달라 단순 비교 주의

•표준점수 동점이어도 백분위는 달라질 수 있음

•대학 환산 시 백분위 기반 변환점수 사용

•수능 최저기준에는 보통 등급을 사용

✅ 종합 해석 및 상담 포인트

•국어 1등급(95백분위)으로 강점, 수학 3등급으로 인문계 중상위권 대학 정시 지원 가능

•탐구 2+3등급 조합: 수능 최저 "2개 합 5" 기준 충족 가능 여부를 대학별로 확인 필요

상담 활용 포인트

🎯 자주 받는 질문 Q&A

•Q. 표준점수가 높으면 무조건 좋은가요?

•→ 예, 그러나 영역별 만점이 달라 직접 비교 어렵습니다

•Q. 백분위 93이면 상위 몇 %인가요?

•→ 상위 7%입니다 (100 − 백분위 = 상위 %)

•Q. 수능 최저 "2등급"이면 표준점수 몇 점인가요?

•→ 연도·영역마다 다르며, 등급컷을 확인해야 합니다

📋 상담 시 체크 사항

•3개 지표 중 어느 지표로 목표 설정할지 먼저 확인

•지원 전형의 수능 최저기준 등급 조합 꼼꼼히 확인

•탐구 2과목 등급을 개별·합산으로 모두 확인

•한국사 절대평가(4등급 이내 기본) 별도 체크

📌 핵심 정리

•표준점수 → 정시 지원 시 주로 활용

•백분위 → 대학 환산 점수 계산에 활용

•등급 → 수시 수능 최저기준 충족 여부 확인

•세 지표를 함께 보아야 정확한 성적 해석 가능

⚠ 상담 시 주의사항

•등급만 보고 지원 가능 여부 단정하지 않기

•동일 등급이라도 영역별 경쟁 강도 다름

•전년도 등급컷은 참고자료, 해당연도 확인 필수

•표준점수·백분위는 매년 달라지므로 최신 자료 활용
